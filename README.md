# Flower Lantern Valley

A small Three.js voxel flower valley with glowing lanterns and hidden messages.

## Publish on GitHub Pages

1. Create a new public GitHub repository.
2. Upload these files to the repository root:
   - `index.html`
   - `main.js`
   - `three.min.js`
   - `.nojekyll`
3. In GitHub, open **Settings > Pages**.
4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Save, wait a minute, then open the Pages URL on your phone.
